# ADR-210: Guest links

**Status:** Accepted (2026-11-11)

## Context

Showing a conversation, or a page being built, to someone without Sirus meant screenshots or an export. The host already has a public route (the one the iPhone uses, a Cloudflare Tunnel in front of the loopback listener), but everything on it needs a paired device or an MCP token. A guest has neither, and must not get anything beyond the one thing shared.

## Decision

- **One link, one thing, read only.** `<public route>/s/<token>` shows either a **conversation** (the owner's choice, from the share icon in the title bar) or a **preview**, a static snapshot of the page open in the embedded browser (browser "⋯" menu → "Compartilhar prévia"). The popover asks for a validity (1 hour, 24 hours by default, 7 days) and, for conversations, whether to hide command output and diffs (on by default) and whether to show attachments and images (off by default). The link is copied when made; the card then shows the address, when it expires, the views, "Desligar link" and "Pronto".
- **Token and store.** 192 random bits, URL-safe; only its SHA-256 hash is kept in `share-links.json` (`0600`, data folder), next to id, kind, title, project, options, expiry and views. A request hashes the token and compares it against every stored hash in constant time. The address exists in full only in the answer that creates the link, so Settings lists links but cannot copy them. At most 50 active links; expired ones are dropped on every change and every ten minutes (a preview's file goes with its row).
- **Public routes.** `GET /s/{token}` and `GET /s/{token}/a/{id}` on the host's HTTP server (both listeners, so the Cloudflare route reaches them as loopback like everything else). Only GET; nothing under `/api/*` is reachable with a link. Every answer, found or not, carries `Cache-Control: no-store`, `X-Robots-Tag: noindex, nofollow`, `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`, `Cross-Origin-Resource-Policy: same-origin` and `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; img-src data: 'self'; font-src data:; base-uri 'none'; form-action 'none'; frame-ancestors 'none'; sandbox` (no script runs on a guest page, and the sandbox makes it an opaque origin). 60 requests a minute per address (Cloudflare's `CF-Connecting-IP`, else the peer) and 600 for all (429). Expiry is checked on every request; the view counter goes up on every page load.
- **Gone is gone.** A token that never existed, one that expired and one turned off get the same 404 page ("Este link não está mais ativo" / "Ele venceu ou foi desligado por quem compartilhou."), in the visitor's language, with no title and no data.
- **The conversation page** is rendered live at every access (so it follows the conversation until the link expires) as dark, dithered HTML with inline CSS and no script: header with title, project · model · date and "Só leitura · vence em X"; the person's messages as bubbles; replies as safe markdown (everything is escaped first; headings, lists, quotes, tables, fenced code, inline code, bold, italic, `http(s)` links only); each reply's tools as one line ("Leu 3 arquivos · rodou 2 comandos"); no composer, no actions. The text goes through two filters first: the worktree, the project folder and the home folder are cut to relative paths (`src/a.rs`, `~/…`), and credentials are masked with the same `redact::mask` the rest of Sirus uses. With output hidden, the tool line is all there is; with it shown, each tool's label, command and the end of its output appear in a `<details>`. Diffs are never served. Images are served only from the link's own conversation and only when asked (`/s/{token}/a/{id}`, the attachment's thumbnail); other attachments appear as a name. Visuals (`sirus_show_visual`) are left out. The latest 400 messages are shown.
- **The preview** is captured in the window by `browser_js/share_capture.js` (run through the same `callAsyncJavaScript` bridge as the agent's browser tools): the DOM is cloned, every stylesheet is read from the CSSOM (or fetched) into one `<style>` with `url()`s as data URIs, images and canvases become data URIs, scripts, frames, plugins, `<base>`, `<link>`, refresh and event handlers are removed, and password, hidden and file fields lose their value. The result is capped at 15 MB (the host takes 16 MB) and sent to the host, which sanitizes it again and serves it under the same headers. It is a snapshot, not a proxy: a local dev server stays private, absolute paths and HMR cannot break it, and nothing live is exposed.
- **Commands.** `share_link_action` (`share_links.rs`, `commands.list`) with `list`, `conversation`, `preview` and `revoke`, usable by a paired device like every host command. Settings → Conexões → "Links ativos" lists them (title, project or "Prévia", expiry, views) with "Desligar".

## Consequences

- The public route's Cloudflare Access policy must let `/s/*` through without a service token, as `/mcp` needs for MCP clients, or guests hit the Access login instead of the page.
- Anyone with the address sees what the page shows until it expires or is turned off; the token is the only credential, so turn off a link that went to the wrong place.
- The snapshot cannot capture what the page keeps out of reach: cross-origin images and stylesheets without CORS, shadow DOM, video, iframes. They are left out, not failed.
- The phone's protocol does not change; no shared types were added.
